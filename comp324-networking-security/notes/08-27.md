## Compromising System Security

### Attacks that breach a system's security
* hacking
* cracking
* social engineering
* war-driving
* war-dialing

### Denial of Service (DoS)
* attacker blocks access for authorized users
* goal is to disrupt availability, not to gain access to or control of the system

### Distributed DoS (DDoS)
* uses many machines (typically a botnet of compromised hosts) to attack one target

### Web attacks
* attacker attempts to breach a web application
* common types:
	* SQL injection
	* cross-site scripting (XSS)

### Session hijacking
* complex attack, not especially common
* attacker takes over an already-authenticated session between the client and the server

### DNS poisoning
* altering Domain Name System (DNS) records on a DNS server to redirect client traffic to malicious sites
* typically used for identity theft (fake sites that harvest credentials)

### Doxing
* locating personal information on an individual and threatening to broadcast it, often via the internet
* can be any personal information about any person; most often aimed at public figures
* becoming more prevalent

## Basic Security Terminology

### People
* Hackers
	* White Hat
		* ethical hackers who use their skills to expose security risks (with permission)
	* Black Hat
		* malicious hackers who break into systems for gain, damage, or theft; illegal
	* Gray Hat
		* in between - may probe systems without permission, but without malicious intent (e.g. find a flaw, then disclose it)
* Script kiddies
* Penetration testers
* Ethical hackers

### Devices
* Firewall
	* filters network traffic
* Proxy server
	* disguises the IP address of an internal host
* Intrusion Detection System (IDS) / Intrusion Prevention System (IPS)
	* monitor traffic, looking for attempted attacks
	* IDS: passive - watches a copy of traffic and only alerts; no impact on throughput
	* IPS: inline - can block malicious traffic, but adds latency and is a potential single point of failure
* DHCP server
	* dynamically assigns IP addresses (plus gateway, DNS, etc.) to hosts
	* typically assigns from the private (RFC 1918) ranges:
		* 10.0.0.0/8      (10.0.0.0 - 10.255.255.255)
		* 172.16.0.0/12   (172.16.0.0 - 172.31.255.255)
		* 192.168.0.0/16  (192.168.0.0 - 192.168.255.255)
