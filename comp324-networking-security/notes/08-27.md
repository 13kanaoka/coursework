## Compromising System Security
### Attacks that breach a system's security
* hacking
* cracking
* social engineering
* war-driving
* war-dialing

#### Denial of Service Attacks (DoS)
* the attacker blocks access to authorized users
	* does not attack the system  
  
#### Distributed DoS (DDoS)
* Uses multiple machines to attack the target

### Web attacks
* In a web attack, the attacker attempts to breach a web application
* Common types:
	* SQL injection
	* cross-site scripting

### Session Hijacking
* complex form of attack, not common
* The attack involves the attacker taking over an authenticated session between the client machine and the serve

### DNS poisoning
* This type of attack involves altering Domain Name System (DNS) records on a DNS server to redirect client traffic to malicious websites
	* typically used for identity theft

### Doxing
* doxing refers to the process of locating personal information on an individual and threatening to broadcasting it, often via the internet
* This can include any personal information about any person; most often used against public figures
* this type of attack is becoming more prevalent
