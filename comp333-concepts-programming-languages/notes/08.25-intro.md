# Racket
Racket is not an industrial level language, but instead a prototyping language that you can use to test and play with fundamental parts of a program during the planning phase

### REPL
Read  
Eval  
Print  
Loop  

## prefix mutation for functions  
| Typical | --> | Racket |
| --- | --- | --- |
| fibonacci(n) | --> | (fibonacci n) |
| 3 + 5 | --> | (+ 3 5) |
| 27 * 3 + 54 * 2 | --> | (+ (* 27 3) (* 54 2)) |

## lists
- `(5 10 15 20)`
- `(a b c d e)`
- `((a b c) (d e f) (g h i))`

function calls are written as lists  
(+ 3 5)  

- \+ is func
- 3 and 5 are params

### Empty lists: null or '( )  
`(empty? '( ))`  
`(empty? '(1 2 3))`  

### List Commands
`x: '(5 10 15 20)`  

`car <list>` gives first  
`car x --> 5`  

`cdr <list>` gives last  
`cdr x --> 20`  

### recursive functions
`(define (sumlist x) ... )`  

base case `(empty? x)` returns 0  
open case `(+ (car x) (sumlist(cdr x)))`
